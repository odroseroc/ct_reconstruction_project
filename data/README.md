# Data Credits

## `richmond/` directory

All the images in this directory originate from [Michael Richmond's educational repository](http://spiff.rit.edu/classes/), which provides high-quality, openly available material for teaching physics and astronomy.

In particular, I have used several `.fit` image files from the [PHYS 445 course dataset](http://spiff.rit.edu/classes/phys445/data/sep20_2003/) to test and validate the dark-field and flat-field calibration algorithms implemented in this project.

All credit for the original data belongs to Prof. Richmond. The files are used here strictly for educational and non-commercial purposes.
